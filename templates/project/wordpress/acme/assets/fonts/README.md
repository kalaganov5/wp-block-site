Шрифты сайта — variable woff2, разбитые по unicode-range (latin, latin-ext, cyrillic, cyrillic-ext), и файл лицензии (OFL).
Скачать, например, с fontsource.org (пакет @fontsource-variable/<шрифт>, файлы *-wght-normal.woff2).
Подключение — assets/css/fonts.css; preload основных файлов — ACME_PRELOAD_FONTS в inc/setup.php.
