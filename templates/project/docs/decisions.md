# Принятые решения

Сюда записываются решения, которые нельзя понять из кода: почему выбран этот вариант и какие отвергнуты.
Новая запись — сверху. Формат вопроса, из которого рождается решение, — в `CLAUDE.md`.

## Шаблон записи

```
## ГГГГ-ММ-ДД. Короткое название решения

**Вопрос.** Что нужно было решить.
**Решение.** Что выбрали.
**Почему.** Причина — числа, ограничения хостинга, требования владельца.
**Отвергнуто.** Варианты и почему не они.
**Что трудно изменить потом.** Адреса страниц, данные в базе, разметка сохранённых блоков.
```
