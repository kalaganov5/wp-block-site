# История изменений

## [Unreleased]

## [2.0.0] — 2026-11-20

Версия про качество: код читается и проверяется машиной, редактор не мешает работать со статьями, SEO и
безопасность встроены с первого дня.

### Добавлено

- **Читаемый код** (глава 15): пределы размера — строка 120, функция 40 строк, файл 250, вложенность 3,
  сложность 10; PHPCS (WordPress + Slevomat), ESLint, Stylelint, Prettier; словарь имён `docs/glossary.md`;
  журнал решений `docs/decisions.md`; формат вопроса владельцу «вопрос · варианты · влияние · рекомендация».
- **Одна команда проверки** `npm run check`: синтаксис, оформление, пределы, безопасность PHP, граница темы и
  плагина, актуальность сгенерированного, тесты, shellcheck, бюджет веса CSS/JS и запрет внешних запросов.
  Её запускают хук `.githooks/pre-commit` (с поиском секретов gitleaks), CI и ручной деплой.
- **Тесты бизнес-правил**: PHP без WordPress (`tools/tests/run.php` + заглушки) и JS (`node --test`).
- **Публичный интерфейс плагина** `inc/api.php`: тема вызывает только его, это проверяется.
- **Удобный редактор**: записи открываются без шаблона, H1 — поле заголовка; на холсте ничто не плавает и не
  прилипает; пустые блоки — подсказка вместо заглушек; сценарий `tools/qa/editor-usability.js`.
- **CSS по блокам**: `blocks/<имя>/style.css` подключается только на страницах с блоком; общие стили —
  `base`, `core-blocks`, `components`.
- **Картинки**: `acme_image()` (размеры, srcset, lazy, fetchpriority), WebP при загрузке.
- **SEO с брифа**: SEO-поля в исходнике контента с проверкой длины, дублей, слагов, H1 и alt; Rank Math без
  мастера и статистики, только нужные модули; коды Яндекс Вебмастера, Google, Bing в настройках; обложки для
  соцсетей по языкам; заголовки архивов и «страница N»; canonical для Polylang; JSON-LD по типам страниц,
  `Service` с ценой, `LocalBusiness`; IndexNow только на открытом боевом; самопроверка SEO в логе деплоя;
  SEO-гейт в CI (`tools/qa/seo-gate.js`).
- **Безопасность**: `inc/security.php` (XML-RPC, перечисление пользователей, версия WordPress, пароли
  приложений), заголовки безопасности и запрет PHP в uploads через `.htaccess`, константы wp-config при деплое.
- **CI/CD**: ручной деплой `manual.sh`; один список страниц `pages.txt` и одна проверка `smoke.sh`; откат файлов
  темы и плагина при сбое после выкладки; установка с нуля на двух версиях PHP; закреплённые версии actions,
  минимальные права, тайм-ауты, Dependabot; дежурная проверка `health.yml`; ежемесячный SEO-аудит со
  сравнением с прошлым отчётом.
- Задачи в `evals/evals.json`: читаемый рефакторинг, удобный редактор, SEO новой страницы.

### Изменено

- Правило «Редактор = сайт» заменено на «Редактор удобен владельцу»: точное превью — по кнопке «Показать
  шаблон», а не по умолчанию.
- В `default` атрибутов блока нет образцов текста: списки — `[]`, форма элемента — `itemShape`.
- Файлы плагина разделены по задачам: `inc/seo/`, `inc/import/`; `helpers.php` темы и плагина заменены на
  файлы с конкретным назначением (`markup.php`, `core.php`, `api.php`).
- Подписи интерфейса — `project/content/strings.js`.
- Минимальные версии: PHP 8.3 (его требует текущий Contact Form 7), WordPress 7.0 — предыдущая основная ветка.
- Кеш страниц ставит и настраивает деплой (Cache Enabler) вместо ручной настройки W3 Total Cache.
- Коммиты — Conventional Commits.
- Предел длины title — 60 символов (был 65).

### Удалено

- `assets/css/site.css` (разнесён по блокам и общим файлам).
- Принудительный режим `template-locked` для записей (включается константой `ACME_TEMPLATE_MODE_POST_TYPES`).

## [1.0.0] — 2026-10-15

Первая версия: блочная тема без сборки и плагин данных, каркас `templates/project`, `scaffold.js`, деплой по
SSH через GitHub Actions, импорт контента из прототипа, Rank Math кодом, Polylang, CF7 + Telegram, GTM с
Consent Mode, QA-скрипты, 14 глав методики.
